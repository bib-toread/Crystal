# 06 · 物品与技能

> 怎么新增装备/消耗品、配它的属性与外观，以及怎么新增一个技能、给技能加新效果。
>
> 相关源码：`Shared/Data/ItemData.cs`(ItemInfo/UserItem)、`Shared/Data/Stat.cs`、`Server/MirDatabase/MagicInfo.cs`、`Server/MirObjects/HumanObject.cs`(技能)、`Server.MirForms/Database/ItemInfoForm.cs`/`MagicInfoForm.cs`。

## 第一部分 · 物品

### 1.1 ItemInfo（物品模板）关键字段

`ItemInfo`（`Shared/Data/ItemData.cs:3`）是「一类物品的定义」，全服一份，存进 `Server.MirDB`。关键字段：

| 字段 | 含义 |
|---|---|
| `Index` | 主键（自增），被掉落/配方/任务/商城按 index 或名字引用 |
| `Name` | 物品名（脚本/掉落表里按名引用，务必唯一且稳定） |
| `Type` | `ItemType` 枚举：Weapon/Armour/Helmet/Necklace/.../Potion/Scroll/Gem/Mount… 决定能装哪个槽、走什么逻辑 |
| `Grade` | 品阶（Common/Rare/Legendary…），影响显示与部分规则 |
| `Shape` | 形状/子类型，配合 `Type` 细分行为（如药水的回血/回蓝、卷轴的种类） |
| `Image` | 图档 index（客户端用 `Libraries.Items.Draw(Image,…)` 画图标） |
| `Durability` | 最大耐久（装备） |
| `Weight` | 重量（影响负重） |
| `Price` | 基础价（买卖、修理计算基准） |
| `StackSize` | 可堆叠数量（>1 表示可叠，如药水/材料） |
| `Bind` | 绑定规则（`BindMode` 标志：捡绑/装绑/不可交易/不可丢弃…） |
| `Unique` | 唯一性限制 |
| `Stats` | **属性字典**（`Stats` 类型），装备的 AC/DC/HP 等都在这里 |
| `RandomStatsId` | 随机附加属性配置 id（关联 `Settings` 随机属性表） |
| `Slots` | 可镶嵌槽数（宝石孔） |
| `StartItem` | 是否新建角色赠送 |
| `NeedIdentify`/`CanMine`/`CanFastRun`/`CanAwakening` 等 | 各种行为开关 |

> 装备的「属性」全在 `Stats` 字典里（`Stat.MaxAC`、`Stat.MaxDC`、`Stat.HP`…）。加属性就是往这个字典写键值，零值不存。

### 1.2 模板 vs 实例：UserItem

玩家身上的每一件具体物品是 `UserItem`（`ItemData.cs:277`），与模板分离：

| UserItem 字段 | 含义 |
|---|---|
| `UniqueID` | 全局唯一实例 id（`Envir.NextUserItemID` 发号） |
| `ItemIndex` | → `ItemInfo.Index`（关联模板） |
| `Info` | 运行期绑定的模板指针（`Envir.BindItem` 按 index 接上） |
| `CurrentDura`/`MaxDura` | 当前/最大耐久 |
| `Count` | 数量（堆叠物） |
| `AddedStats` | 精炼/强化的附加属性 |
| `Awake` | 觉醒数据 |
| `RefinedValue`/`RefineAdded` | 精炼 |
| `Slots[]` | 镶嵌的子物品（递归 UserItem） |
| `ExpireInfo`/`RentalInformation`/`SealedInfo` | 限时/租赁/封印 |

**实例读最终属性走** `GetTotal(stat) = AddedStats[stat] + Info.Stats[stat]`（`ItemData.cs:511`）——模板属性绝不复制进实例，改模板会影响所有该类物品。

### 1.3 新增一个物品的步骤

1. （如需新图标外观）用 `LibraryEditor` 把图标做进物品图档，记下 `Image` index。
2. 打开 `Server.exe` → 菜单「数据库 → 物品」，点 Add 新增 `ItemInfo`（自动分配 `Index`）。
3. 填字段：`Name`、`Type`（决定装备槽/用途）、`Shape`、`Image`、`Grade`、`Durability`、`Weight`、`Price`、`StackSize`、`Bind`。
4. 配属性：在属性区填 `Stats`（MaxAC/MaxDC/HP… 按需），需要随机附加设 `RandomStatsId`，需要宝石孔设 `Slots`。
5. 关闭窗体（自动 `SaveDB` 写库 + 备份）。
6. 让它进游戏：
   - 商店出售 → 在对应 NPC 脚本 `[@BUY]` 段或商城里上架；
   - 怪物掉落 → 在 `Envir/Drops/{怪名}.txt` 加一行（见 [07](07-怪物与AI.md)）；
   - 任务奖励/配方产物 → 在 `Quests`/`Recipe` 文本里按**名字**引用；
   - 直接给 → GM 命令或 NPC 脚本 `GIVEITEM 物品名 数量`。
7. **重启服务器**让 `Envir.Main` 重新 `LoadDB`（新物品入的是库）。

### 1.4 给 ItemInfo 加一个新字段（进阶）

若现有字段不够，要给 `ItemInfo` 加一个持久化字段，遵守 [03 §5.4 版本兼容](03-服务端架构.md#54-版本兼容新增字段必读)：

1. `Envir.Version` +1。
2. `ItemInfo.Save` 末尾 `writer.Write(新字段)`。
3. `ItemInfo` 构造器末尾 `if (Envir.LoadVersion >= 新版本) 新字段 = reader.ReadXxx();`。
4. **若是属性数值，优先加一个 `Stat` 枚举值塞进 `Stats`**，免改 Save/Load。
5. 编辑器要显示该字段，在 `ItemInfoForm` 加对应控件并绑定读写。

### 1.5 客户端物品/装备外观

- **图标**：物品格子用 `Libraries.Items.Draw(item.Info.Image, …)` 画，改 `Image` 即换图标。
- **装备穿上后的人物外观**：由服务端 `S.ObjectPlayer`/`S.PlayerUpdate` 下发的 `Armour`/`Weapon`/`Hair`/`WingEffect` **整数 ID** 决定（外观与玩法数值解耦，客户端只认 ID）。新增装备外观：
  1. 服务端让该装备触发对应外观 ID（通常 `ItemInfo.Shape`/专门字段映射到外观）。
  2. 客户端把新图档放进对应 `Libraries.*` 数组（铠甲 `CArmours`/`AArmours`/`ARArmours`，武器 `CWeapons`/`AWeaponsL/R`，发型 `CHair`，翅膀 `CHumEffect`…）。
  3. `SetLibraries()`（`PlayerObject.cs:252`）一般无需改——它已按 ID 索引数组；仅当新外观跨职业/性别偏移规则或需要新武器层时才扩 `SetLibraries`/`Draw`。
  详见 [04 §3.4 角色分层渲染](04-客户端架构.md#34-角色分层渲染)。

## 第二部分 · 技能 / 魔法

### 2.1 数据：MagicInfo 与 UserMagic

- `MagicInfo`（`Server/MirDatabase/MagicInfo.cs`）= 技能定义：`Spell`(枚举 id)、`BaseCost`/`LevelCost`(蓝耗)、`Level1/2/3`(各级所需角色等级)、`Need1/2/3`(各级所需技能经验)、`DelayBase`(冷却)、`PowerBase`/`PowerBonus`(威力)、`Range`(射程)、各种 `Multiplier`。存进 `Server.MirDB`。
- `Spell` 是技能枚举（`Shared/Enums.cs`），如 `FireBall`、`Healing`、`ThunderBolt`、`Slaying`。**技能的「身份」是 `Spell` 枚举值**。
- `UserMagic` = 玩家已学技能实例：`Spell`、`Level`、`Experience`、`Key`(快捷键)、`CastTime`，方法 `GetPower()`/`GetDamage()`/`GetDelay()` 按等级算实际值。挂在 `CharacterInfo.Magics`。

### 2.2 施放路径回顾

完整链路见 [03 §4.2](03-服务端架构.md#42-技能魔法系统)。要点：

```
客户端 C.Magic{Spell,方向,目标}
  → MirConnection.Magic 节流
  → HumanObject.Magic (HumanObject.cs:3400): 校验/扣蓝/解析目标
      → 大 switch(spell) 分发到效果方法(如 Fireball/Healing)
          多数构造 DelayedAction(DelayedType.Magic,...) 入 ActionList
  → Process(DelayedAction) → CompleteMagic (:5903):
      target.Attacked / AddBuff / ApplyPoison; 广播 S.ObjectMagic/ObjectEffect
```

**练级**：成功施放后给 `UserMagic.Experience` 加经验（受 `SkillGainMultiplier` 影响），满则升级广播 `S.LevelMagic`；被动技能随等级增强。

### 2.3 新增一个技能（完整步骤）

假设要加一个新技能 `FrostNova`（范围冰冻+伤害）：

**服务端：**

1. **枚举**：`Shared/Enums.cs` 的 `Spell` 加 `FrostNova`。
2. **技能数据**：菜单「数据库 → 技能」加一条 `MagicInfo`（`Spell=FrostNova`、蓝耗、各级等级/经验、射程、威力）。
3. **学习途径**：通过 NPC 脚本 `GIVESKILL`、升级自动给、或技能书物品使用来让玩家学会（产出 `UserMagic`）。
4. **效果分发**：在 `HumanObject.Magic` 的大 `switch(spell)`（`HumanObject.cs:3499`）加：
   ```csharp
   case Spell.FrostNova:
       FrostNova(magic, target, location);
       break;
   ```
5. **效果方法**：实现 `private void FrostNova(UserMagic magic, MapObject target, Point location)`：
   - 即时型直接对范围内对象 `Attacked` / `ApplyPoison(冰冻)`；
   - 延迟型构造 `DelayedAction(DelayedType.Magic, Envir.Time + 延迟, magic, GetAttackPower(Stats[Stat.MinMC], Stats[Stat.MaxMC]), location)` 入 `ActionList`，并在 `CompleteMagic` 的 `switch` 加分支真正结算 + 广播 `S.ObjectMagic{Spell=FrostNova,...}`。
   - 伤害用魔攻 `MinMC~MaxMC`（魔法系）或道攻 `MinSC~MaxSC`（道术系），走 `DefenceType.MAC`。
   - 范围目标用 `FindAllTargets(范围, 中心)` 之类工具枚举。

**客户端：**

6. **施法/特效动画**：在 `GameScene` 处理 `S.ObjectMagic` 时，按 `Spell=FrostNova` 生成对应特效（参照已有技能在 `PlayerObject`/`GameScene` 的 `ObjectMagic` 处理与 `Effect`/`Missile` 创建，见 [04 §3.5](04-客户端架构.md#35-特效与飘字)），并配音效。若该技能是落地持续型（像火墙），在 `SpellObject.Load` 的 `switch(Spell)` 加分支。
7. **图档**：把技能特效做进 `Libraries.Magic*`/`Effect` 图档。

**生效**：技能数据进库 → 重启服务器；客户端重新编译。注意协议若新增了封包字段要重配版本哈希（见 [02 §11](02-通信协议.md#11-坑位清单)）。

### 2.4 给已有技能加一种新效果（轻量）

不加新技能，只想给现有技能叠加一个效果（如让某攻击技额外上一层减速）：

- 找到该技能在 `HumanObject.Magic`/`CompleteMagic` 的处理分支，在结算处追加 `target.ApplyPoison(new Poison{PType=PoisonType.Slow,...}, this)` 或 `target.AddBuff(...)`。
- 若效果是新的状态类型，见 [03 §4.3](03-服务端架构.md#43-状态系统buff-与-中毒) 与本册 [07](07-怪物与AI.md) 末尾「新增状态」要点：`PoisonType`/`BuffType` 加枚举 + `ApplyPoison`/`ProcessPoison` 或 `ProcessBuffs` 加行为 + 客户端体色/图标。

### 2.5 属性系统扩展（加一个新属性）

技能/装备常需要新属性支撑（如「冰冻强度」）。加属性见 [03 §3](03-服务端架构.md#第三部分--属性系统)，三步：

1. `Shared/Data/Stat.cs` 的 `enum Stat` 加成员（byte 值唯一）。
2. 让它有来源：写进装备/buff 的 `Stats` 即被 `RefreshStats` 自动叠加；要百分比加成则在 `RefreshStats` 末尾加一行 `+= 基础 * XxxRatePercent / 100`。
3. 在战斗管线读 `Stats[新属性]` 让它生效（参照 `Reflect`/`CriticalRate` 用法）。
4. 要在客户端面板显示则同步属性面板封包与本地化键。
