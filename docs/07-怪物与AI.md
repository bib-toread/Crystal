# 07 · 怪物与 AI

> 怎么新增一个怪物、配它的属性/刷新/掉落，以及怎么写一个全新的怪物 AI 行为。
>
> 相关源码：`Server/MirDatabase/MonsterInfo.cs`、`Server/MirObjects/MonsterObject.cs`、`Server/MirObjects/Monsters/*.cs`、`Server/MirDatabase/RespawnInfo.cs`、`Server.MirForms/Database/MonsterInfoForm.cs`、`Server.MirForms/DropBuilder/`。

---

## 第一部分 · 怪物数据 MonsterInfo

`MonsterInfo`（`Server/MirDatabase/MonsterInfo.cs:6`）是怪物模板，存进 `Server.MirDB`。关键字段：

| 字段 | 含义 |
|---|---|
| `Index` | 主键（自增），被 `RespawnInfo.MonsterIndex` 引用 |
| `Name` | 怪物名（掉落表文件名、脚本引用都按名） |
| `Image` | `Monster` 枚举：决定客户端用哪套图档 |
| **`AI`** | **整数，决定行为子类**（见第二部分），由 `GetMonster` 的 switch 选 |
| `Effect` | 特效编号 |
| `Level` | 等级 |
| `ViewRange` | 视野/索敌范围 |
| `CoolEye` | 反隐探测概率 |
| `AttackSpeed` | 攻击间隔 |
| `MoveSpeed` | 移动间隔 |
| `Experience` | 击杀给的经验 |
| `Stats` | 属性字典（HP/MinAC/MaxAC/MinDC/MaxDC…，与物品共用 `Stats`） |
| **`DropPath`** | 掉落文件名（空则用 `{Name}.txt`），关联 `Envir/Drops/` |
| `CanTame`/`CanPush`/`CanRecall`/`IsBoss` | 行为开关 |

> 「怪物模板是数据，怪物行为是代码」：`AI` 字段是数据，但它选中的子类是代码。属性强度由 `Stats` + `Settings` 的稀有度倍率系统调节。

### 新增一个怪物（数据）的步骤

1. （如需新外观）`LibraryEditor` 把怪物美术做进 `Monsters` 图档；在 `Shared/Enums.cs` 的 `Monster` 枚举加条目，记下它对应的图档 index。
2. 菜单「数据库 → 怪物」Add 新增 `MonsterInfo`（自动分配 `Index`）。
3. 填 `Name`、`Image`（选刚加的 `Monster` 枚举）、`AI`（选一个现成行为编号，或你将新建的编号）、`Level`、`ViewRange`、`AttackSpeed`/`MoveSpeed`、`Experience`、`Stats`（HP/攻/防）。
4. 填 `DropPath`（留空则掉落文件名 = 怪物名）。
5. 关窗 `SaveDB`。
6. 让它出现在世界：在地图 `MapInfo` 里加刷怪点（见第三部分）。
7. 配掉落（第四部分）。
8. **重启服务器**（怪物入的是库）。

## 第二部分 · 怪物 AI 架构

### 2.1 AI 编号 → 子类映射

怪物行为由 `MonsterInfo.AI`（int）决定，在工厂方法 `MonsterObject.GetMonster(MonsterInfo info)` 的大 `switch (info.AI)`（`MonsterObject.cs:18` 起）映射到具体子类：

```csharp
switch (info.AI)
{
    case 1: case 2: return new Deer(info);          // 被动（鹿）
    case 4:  return new SpittingSpider(info);        // 直线攻击带毒
    case 8:  return new AxeSkeleton(info);           // 远程投射+恐惧
    case 10: return new FlamingWooma(info);          // 简单魔法攻击
    ...
    case 255: return new StoneTrap(info);
    default: return new MonsterObject(info);         // 纯近战基类行为
}
```

多个怪物可共用同一个 AI 子类（同一行为模板，属性不同）。`default` 是纯近战基类。

### 2.2 基类处理循环与可覆写钩子

`MonsterObject.Process()`（`MonsterObject.cs:1192`）每 tick：清理失效目标/超时驯服 → `ProcessAI()` → `ProcessBuffs/Regen/Poison`。

`ProcessAI()` 内按节奏调用一组 **virtual 钩子**（子类按需覆写）：

| 钩子 | 默认行为 |
|---|---|
| `ProcessSearch()` | 到 `SearchTime` 按概率 `FindTarget()` 找目标 |
| `FindTarget()` | 在 `ViewRange` 内由近及远扫格子找可攻击目标 |
| `ProcessRoam()` | 无目标时巡逻：走路线 `ProcessRoute`、跟随主人、或随机转向走动 |
| `ProcessTarget()` | 有目标时：`InAttackRange()` 则 `Attack()`，否则 `MoveTo(目标)` |
| `InAttackRange()` | 默认相邻 1 格即可攻击 |
| `Attack()` (virtual) | 默认近战：广播攻击封包、`GetAttackPower` 算伤害、对目标 `Attacked`/加 `DelayedAction` |
| `Die()` | 死亡处理（掉落/经验/移除） |
| `MoveTo`/`Walk`/`Turn` | 寻路与移动 |

时间片：`SetOperateTime()`（`MonsterObject.cs:1232`）汇总所有计时器取最近的，决定下次被 `Process` 的时机（见 [03 §1.3](03-服务端架构.md#13-对象生命周期与调度)）。

### 2.3 典型子类覆写什么（参照模板）

| 子类 | 行为模板 | 覆写要点 |
|---|---|---|
| `Deer` | 被动（受击才反击/逃跑） | 改索敌逻辑 |
| `AxeSkeleton` | 远程射手 | `AttackRange`(=6) + `InAttackRange()` 远距离判定 + `Attack()` 改 `ProjectileAttack`(投射物) + 恐惧后撤 |
| `SpittingSpider` | 直线穿透+毒 | `InAttackRange()` 菱形判定 + `Attack()` 用 `LineAttack` + 命中后 `PoisonTarget`(绿毒) |
| `FlameMage` | 法系 AoE | 覆写 `CompleteRangeAttack()` 做范围群伤 + 恐惧后撤 |
| `FlamingWooma` | 最简近战 | 只覆写 `Attack()`，`DelayedAction(DelayedType.Damage)` 延迟结算 |

**继承复用**：可以继承更贴近的现成子类（如 `RightGuard`/`HarvestMonster`）复用其框架，而非从 `MonsterObject` 从头写。

## 第三部分 · 写一个新怪物 AI（完整步骤 + 骨架）

### 步骤

1. 在 `Server/MirObjects/Monsters/` 新建 `MyBoss.cs`，继承 `MonsterObject`（或更贴近的子类）。
2. 选一个**未占用**的 AI 编号，在 `MonsterObject.GetMonster` 的 `switch` 加 `case <编号>: return new MyBoss(info);`。
3. 按需覆写钩子：`InAttackRange()`（攻击范围）、`Attack()`（攻击表现+伤害）、`ProcessTarget()`（追击/走位/技能选择）、`Die()`（特殊死亡）等。
4. 攻击表现要 `Broadcast(new S.ObjectAttack/ObjectRangeAttack…)` 让客户端播放动画；伤害用 `GetAttackPower(MinDC,MaxDC)` 经 `DelayedAction`/`Attacked`/`LineAttack`/`ProjectileAttack` 结算。
5. 在 `MonsterInfo` 数据里把该怪 `AI` 设成第 2 步的编号。重启或重载生效。

### 最小自定义 AI 骨架（含群体技能）

```csharp
using Server.MirDatabase;
using S = ServerPackets;

namespace Server.MirObjects.Monsters
{
    public class MyBoss : MonsterObject
    {
        private long _skillCooldown;             // 自定义技能冷却

        protected internal MyBoss(MonsterInfo info) : base(info) { }

        // 覆写：攻击判定范围（改成 3 格内可攻击）
        protected override bool InAttackRange()
        {
            return Target.CurrentMap == CurrentMap
                && Functions.InRange(CurrentLocation, Target.CurrentLocation, 3);
        }

        // 覆写：追击 + 技能选择（特殊技能的决策点）
        protected override void ProcessTarget()
        {
            if (Target == null || !CanAttack) return;

            if (Envir.Time >= _skillCooldown && InAttackRange())   // 冷却好 + 在范围 → 群体技
            {
                CastAoE();
                _skillCooldown = Envir.Time + 8000;                // 8 秒冷却
                return;
            }

            if (InAttackRange()) { Attack(); return; }             // 否则普攻
            MoveTo(Target.CurrentLocation);                        // 不在范围则追击（复用基类寻路）
        }

        // 覆写：普通攻击表现与伤害
        protected override void Attack()
        {
            if (!Target.IsAttackTarget(this)) { Target = null; return; }

            Direction = Functions.DirectionFromPoint(CurrentLocation, Target.CurrentLocation);
            Broadcast(new S.ObjectAttack { ObjectID = ObjectID, Direction = Direction, Location = CurrentLocation });

            ActionTime = Envir.Time + 300;
            AttackTime = Envir.Time + AttackSpeed;

            int damage = GetAttackPower(Stats[Stat.MinDC], Stats[Stat.MaxDC]);
            if (damage == 0) return;
            // 延迟 300ms 结算单体伤害（与挥砍动画对齐）
            ActionList.Add(new DelayedAction(DelayedType.Damage, Envir.Time + 300,
                Target, damage, DefenceType.ACAgility));
        }

        // 自定义群体技能：以目标为中心 2 格范围 AoE（魔法伤害）
        private void CastAoE()
        {
            Broadcast(new S.ObjectRangeAttack {
                ObjectID = ObjectID, Direction = Direction,
                Location = CurrentLocation, TargetID = Target.ObjectID });

            int damage = GetAttackPower(Stats[Stat.MinMC], Stats[Stat.MaxMC]);
            foreach (MapObject t in FindAllTargets(2, Target.CurrentLocation))
                t.Attacked(this, damage, DefenceType.MAC);
        }
    }
}
```

并在 `GetMonster` 加：`case 200: return new MyBoss(info); // 自定义 Boss`（编号需未占用）。

> 客户端怪物表现（图档/帧/特效）见第五部分；若怪物有特殊出生动画或攻击特效，还要动客户端 `MonsterObject` 对应分支。

## 第四部分 · 刷怪与掉落

### 4.1 刷怪 RespawnInfo

怪物运行期实例不持久化，靠刷新点 `RespawnInfo`（`Server/MirDatabase/RespawnInfo.cs:6`）在地图加载时生成。字段：

| 字段 | 含义 |
|---|---|
| `MonsterIndex` | → `MonsterInfo.Index`（刷哪个怪） |
| `Location` | 刷新中心坐标 |
| `Count` | 数量 |
| `Spread` | 扩散半径 |
| `Delay` | 刷新间隔 |
| `RandomDelay` | 随机延迟 |
| `Direction` | 初始朝向 |
| `RoutePath` | 巡逻路线文件（`Envir/Routes/`） |
| `RespawnIndex` | 刷新点编号（脚本可按编号控制刷怪） |
| `SaveRespawnTime`/`RespawnTicks` | 定时刷新（配合存档，重启后定时 BOSS 不重置） |

**配置方式**：菜单「数据库 → 地图」选地图 →「Add 刷新点」，或用**可视化地图编辑器**（`MapInfoForm` 里的按钮启动 `VForm`）在地图图片上拖拽摆放刷怪点。详见 [09](09-地图与玩法系统.md)。

### 4.2 掉落文件格式

掉落表是文本，放在 `Envir/Drops/`，文件名 = `MonsterInfo.DropPath` 或怪物名。由 `DropInfo.Load`（`MonsterInfo.cs:372`）解析，入口 `Envir.ReloadDrops()`。

**行格式**：`数量分之一概率 物品名 [Q]`

```
; 这是注释,分号开头整行忽略
Gold 500              ; 必掉 500 金币(也可写成几率金币)
1/1 木剑              ; 1/1 = 必掉
50/100 铁矿           ; 50% 概率掉铁矿
1/1000 屠龙           ; 千分之一掉屠龙
2/100 金疮药 Q        ; Q 标记"仅任务时掉落"

GROUP{                ; 组掉落：组内按规则取
1/100 项链A
1/100 项链B
}
```

- `GROUP{...}`：组掉落（`*` 随机取一 / `^` 取首个，按实现）。
- `#INSERT[子文件]`：把另一个掉落文件拼进来（共享掉落段）。
- `Gold N`：金币掉落。
- 用 `Server.exe` 菜单「系统 → 掉落编辑器」可视化生成这个文件（选怪 → 按物品类型挑选 → 设掉率），改完用菜单「重载 → 掉落」热生效。

## 第五部分 · 客户端怪物表现

- **选图档**：`MonsterObject.Load()` 的 `switch (BaseImage)`（`MonsterObject.cs:150`）默认走 `Libraries.Monsters[(ushort)BaseImage]` 自动加载；只有特殊图集（宠物/城门/攻城/龙）才需加 case。
- **帧定义**：**首选**把帧表内嵌进 `.Lib` 图档（运行时 `BodyLibrary.Frames` 自动读取）；若图档无内嵌且不符合 `DefaultMonster` 模板（`Frames.cs:23` 的通用：站立0/行走32/攻击80/受击128/死亡144），在 `Frames.cs` 加专属 `FrameSet` 并在 `MonsterObject` 的 Frames 关联。
- **出生/攻击特效/音效**：在 `Load()` 的 Special Actions、Effect 与 `DrawEffects()` 加 case；`BaseSound = BaseImage*10` 决定音效基址。

详见 [04 §3](04-客户端架构.md#第三部分--对象表现层)。

### 客户端新增怪物速记

1. `Shared/Enums.cs` 的 `Monster` 枚举加条目（图档索引）。
2. 一般无需改 `MonsterObject.Load` —— 默认按 `Libraries.Monsters[index]` 加载。
3. 帧表优先内嵌图档；不行才在 `Frames.cs` 加 `FrameSet`。
4. 特殊表现（专属攻击特效/出生动画）才需加客户端分支。
